Один файл — одно свойство, которое возникает только при комбинировании нескольких технологий. Эмерджентные свойства нельзя получить от одного компонента изолированно — они появляются исключительно на стыке взаимодействий. Примеры: fault-tolerance из комбинации agent-pool + retries, semantic memory из LLM + vector store + consolidation loop.
