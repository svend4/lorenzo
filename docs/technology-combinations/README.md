## Главная находка диалога

Паттерн **«скромные родители → мощные дети»** — ни один компонент по отдельности не революционен, но в нужной комбинации они дают свойства, которых нет ни у одного SaaS. См. [synthesis-tables/01-08-summary.md](synthesis-tables/01-08-summary.md).
