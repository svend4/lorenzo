## 22. Glossary of Reference Examples

В качестве иллюстраций используется экосистема `svend4` с 7 Repos:

- **[info1](01-интегральный-анализ-профиля-svend4.md)** (Level 1) — 74+ Markdown-документа с α-уровнями 
  (-4..+4), методологический угол
- **[pro2](01-интегральный-анализ-профиля-svend4.md)** (Level 3) — Q6-концепты, граф знаний, bidir-цикл, 
  семантический угол
- **meta** (Level 1) — 256 CA-правил + 64 гексаграммы, символьный 
  угол
- **data2** (Level 1) — 310+ томов ЕТД (Единая Теория Движения)
- **data7** (Level 2) — граф знаний, K₀→K∞ трансформация
- **infosystems** (Level 2, домен [pro2](01-интегральный-анализ-профиля-svend4.md)) — архитектура ИС
- **ai_agents** (Level 2, домен [pro2](01-интегральный-анализ-профиля-svend4.md)) — ИИ-агенты и мультиагентные 
  системы

Плюс 5 "расширенных" адаптеров (не в registry, но useable):

- **ObsidianAdapter** — локальный Obsidian vault ([[wikilinks]])
- **ArxivAdapter** — arXiv API с 12h cache
- **GitHubTopicAdapter** — discovery по [GitHub](../01-svyazi/03-component-catalog.md) топику
- **JSONLAdapter** — JSON Lines files
- **[AutoAdapter](141-4-nautilus-portal-as-reference-substrate.md)** — любой repo с nautilus.json в корне
