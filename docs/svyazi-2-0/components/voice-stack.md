## Описание

Локальный speech→text→LLM transform и более широкий local‑first knowledge workspace с recording / transcription.

## Ключевые компоненты и паттерны

- Whisper локально
- Ollama post‑processing
- Handy / OpenWhispr / GigaAM
- Live transcription
- Diarization
- Semantic links
- SQLite
