## Использование

```bash
python scripts/improve_semantic_search.py --query "outreach"
```

Все документы раздела индексированы в поисковой базе репозитория и доступны через семантический поиск. Используйте инструменты репозитория для навигации: семантический поиск, BM25, граф концептов и карту связей. Документы структурированы по стандарту базы знаний: summary-блок, теги, callout, оглавление и ссылки. Раздел обновляется автоматически при запуске скриптов группы reports и quality из пакета improve_*.py. Для автоматизации работы с разделом используйте скрипты группы improve_run_all.py с флагом --group.
