Раздел посвящён архитектуре Svyazi 2.0. Содержит 8 документов с анализом и примерами. Ансамбли представляют синергетические комбинации OSS-репозиториев для построения Knowledge OS. Для поиска по этому разделу используйте инструменты семантического поиска репозитория Lorenzo.

## Использование

```bash
python scripts/improve_semantic_search.py --query "Ансамбли проектов"
```
