# NGT Memory: ассоциативный граф

## Что это

Проект решает задачу объединения лингвистической типизации отношений с семантическим пониманием LLM для построения ассоциативного графа памяти. Ключевая идея: преодолеть ограничения подхода «только лингвистика» (не масштабируется на большие объёмы) через детерминированный код и LLM-извлечение структуры.

## Ключевые особенности

- **Измерение качества структуры:** Задача метрирования извлечённой структуры уже решена в рамках проекта (контраст с открытыми вопросами в других исследованиях)
- **Паттерн LLM + детерминированный код:** Проект следует модели преобразования семантики LLM в детерминированную структурированную форму
- **Авторская экспертиза:** Автор имеет лингвистический фон (ВМК МГУ + аспирантура), что обеспечивает обоснованную типизацию отношений

NGT Memory является прямым аналогом компонентов Svyazi в рамках паттерна «LLM + детерминированный код → структура». Проект вносит решение для слоя memory, обеспечивая масштабируемую обработку и качественное измерение извлечённых структур знаний.
