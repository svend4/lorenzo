# Wikontic: семантический граф

## Что это

Wikontic — проект по созданию семантического графа, разрабатываемый Аллой Чепуровой (AIRI, лаборатория Cognitive AI Systems). Решает задачу автоматической нормализации и объединения синонимичных сущностей в едином графе без необходимости ручного описания правил.

## Ключевые особенности

- **Автоматическая нормализация:** Решает класс проблем нормализации данных (например, kubernetes / k8s / кубер → одна сущность) через автоматические механизмы вместо ручного ведения синонимов
- **Семантическое объединение:** Работает со слоем абстракции для обнаружения и связывания семантически близких понятий в едином графе
- **Архитектурная значимость:** Документ содержит описание рисков и ограничений, требующих изучения перед принятием архитектурных решений
