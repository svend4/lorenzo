# Yodoca: консолидация и забывание

## Что это
Yodoca — архитектурное продолжение Svyazi на уровне agentic memory. Проект реализует систему управления памятью ИИ-агента, позволяющую ему сохранять важную информацию и избирательно забывать лишнее, используя SQLite в качестве хранилища.

## Ключевые особенности
- **Selective memory:** Архитектура, которая учит ИИ-агента различать важную информацию и забывать нерелевантное содержимое
- **SQLite хранилище:** Использование легковесной базы данных для персистентного хранения состояния памяти агента
- **Консолидация данных:** Механизм обработки и структурирования информации для долгосрочного сохранения в памяти

## Интеграция с Svyazi
Yodoca расширяет концепцию Svyazi, добавляя специализированный слой управления памятью для агентов. Это не просто аналог, а архитектурное развитие на уровне долгосрочной памяти, которое позволяет агентам эффективнее работать с накопленным контекстом в рамках коллаборативной системы.
