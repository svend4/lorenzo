# mclaude

Проект многоагентной оркестрации, предназначенный для координации параллельного выполнения задач несколькими агентами. Решает задачу синхронизации и управления взаимодействием между агентами через механизмы передачи управления, очередей сообщений и общей памяти.

## Ключевые особенности

- **Параллельное выполнение:** поддержка одновременной работы нескольких агентов с механизмами синхронизации
- **Handoff-механизмы:** передача управления между агентами с сохранением контекста выполнения
- **Mailbox система:** асинхронная очередь сообщений для обмена данными между компонентами
- **Распределённые блокировки (locks):** примитивы синхронизации для защиты общих ресурсов
- **Shared memory:** общее адресное пространство для координации состояния агентов

## Интеграция с Svyazi

mclaude является центральным компонентом слоя orchestration в архитектуре Svyazi 2.0, обеспечивая основу для координации многоагентных систем. Проект интегрируется с AgentFS, knowledge-space и agent-memory-mcp для создания полнофункциональной платформы управления агентами.
