# Proposal: Agentfs × Memnet

## Что это
Проект предлагает интеграцию knowledge-слоя (Agentfs) и memory-слоя (Memnet) для создания единой системы управления знаниями и памятью агента. Agentfs обеспечивает персистентную память эпизодов, а Memnet хранит структурированный граф знаний, позволяя реализовать контекстно-зависимый retrieval с временной семантикой.

## Ключевые особенности
- **Персистентная память эпизодов:** Agentfs обеспечивает долгоживущее хранилище событий и опыта агента
- **Структурированный граф знаний:** Memnet организует информацию в виде связного графа для эффективного поиска и анализа
- **Контекстно-зависимый retrieval:** Episodes из Agentfs преобразуются в узлы графа Memnet с поддержкой временной семантики при извлечении информации
