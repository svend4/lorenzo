# Proposal: Wikontic × Yodoca

## Что это

Проект предлагает интеграцию knowledge-слоя (Wikontic) и memory-слоя (Yodoca) для создания гибридной системы управления знаниями и памятью. Wikontic обеспечивает персистентную память эпизодов, тогда как Yodoca хранит структурированный граф знаний. Цель — реализовать контекстно-зависимый retrieval с временной семантикой.

## Ключевые особенности

- **Episodes as Graph Nodes:** Episodes из Wikontic становятся узлами графа в Yodoca, обеспечивая связь между эпизодической и декларативной памятью

- **Персистентная память эпизодов:** Wikontic гарантирует долговременное хранение эпизодических данных с сохранением контекста

- **Структурированный граф знаний:** Yodoca организует информацию в виде графа, обеспечивая семантическую связность и временну́ю аннотацию
