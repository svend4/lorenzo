# Карта найденных проектов и паттернов

## Что это

Документ, который картирует и систематизирует проекты и архитектурные паттерны, обнаруженные в ходе исследования экосистемы агентных систем. Служит справочником для выявления технических решений, которые могут быть интегрированы в слой memory и orchestration платформы Svyazi 2.0.

## Ключевые особенности

- **Фокус на агентных системах:** решения разработаны для агентов, а не для людей, что определяет архитектурные принципы
- **Active Open Source:** база проектов растёт почти ежедневно, отражая актуальное состояние экосистемы
- **Knowledge layer:** документирует внешний слой управления знаниями для агентов, критичный для RAG и orchestration

## Интеграция с Svyazi

Карта служит фундаментом для идентификации паттернов, которые должны быть интегрированы в архитектуру memory-layer Svyazi 2.0. Связана с компонентами knowledge-space, orchestration и security через анализ существующих решений (mclaude, AI Factory, Rufler, LiteParse). Обеспечивает roadmap для self-improvement и collaboration функций платформы.
