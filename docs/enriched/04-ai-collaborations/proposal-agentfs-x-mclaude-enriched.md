# Proposal: Agentfs × Mclaude

## Что это

Предложение интеграции knowledge-слоя (Agentfs) и orchestration-слоя (Mclaude) для создания унифицированной архитектуры агентных систем. Agentfs предоставляет файловую систему знаний с рёбрами, Mclaude управляет агентными пайплайнами, что позволяет оркестратору навигировать по графу знаний как по рабочему пространству.

## Ключевые особенности

- **Файловая система знаний:** Agentfs предоставляет структурированное хранилище знаний с явной графовой структурой (рёбра между узлами)
- **Граф как рабочая память:** Mclaude использует граф Agentfs в качестве рабочей памяти оркестратора для навигации и контекстуализации агентных операций
- **Интеграция слоёв:** Разделение ответственности — знание (Agentfs) и управление пайплайнами (Mclaude) как две дополняющие компоненты одной системы
