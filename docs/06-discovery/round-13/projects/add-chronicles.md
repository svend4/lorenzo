## Ключевые идеи

### Agent Feedback Loop (из статьи)

```
Задача → Агент → Результат → Оценка результата
                                    ↓
                          Обратная связь в промпт
                                    ↓
                          Следующая итерация → лучший результат
```

Традиционный CI/CD: код → тест → деплой.  
ADD: задача → агент → **оценка агентом → переработка агентом** → деплой.

### Принципы трансформации

1. **Не заменять**, а дополнять: агент встраивается в существующий пайплайн
2. **Feedback первичен**: без петли обратной связи агент не улучшается
3. **Итеративно**: каждая хроника = одна конкретная трансформация

## Паттерн feedback loop

| Шаг | Что происходит |
|-----|----------------|
| 1. Task | Агент получает задачу (тикет, баг, PR) |
| 2. Act | Агент выполняет действие |
| 3. Eval | Автоматическая или полуавтоматическая оценка результата |
| 4. Store | Оценка сохраняется в memory |
| 5. Improve | Следующая задача использует прошлый контекст |
