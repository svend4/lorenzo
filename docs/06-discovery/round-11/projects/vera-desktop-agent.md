# Vera — минималистичный локальный десктопный агент

**Автор:** неизвестен (статья декабрь 2025)  
**Хабр:** https://habr.com/ru/articles/972260/  
**GitHub:** не найден явно — уточнить  
**Слой:** desktop-agent / local / privacy  
**Дата:** декабрь 2025  
**Уникальность:** Полностью открытый и локальный десктопный агент на **llama-cpp-python + GGUF**: не привязан к конкретной модели, пользователь выбирает сам. Принцип: никаких платных подписок, никаких серверов — всё на устройстве. Управление ОС (громкость, яркость, питание). Планируется интеграция с Home Assistant.

## Философия

> «Голосовой ассистент не должен быть шпионом,  
>  которому нужен интернет или подписка».

Vera = прямой ответ на проблему Алисы, Siri, Google Assistant — все они требуют облака.

## Стек

- **llama-cpp-python** — инференс без Python-обёрток над CUDA
- **GGUF формат** — любая совместимая модель (по умолчанию Qwen, но меняется)
- По умолчанию модель — Qwen, но не ограничен ею
- Управление системой: громкость, яркость, shutdown/restart

## Планируется

- Интеграция с Home Assistant → локальный умный дом без облака

## Почему важно для Svyazi

Vera — наименьший возможный desktop agent: один процесс, один GGUF.  
Паттерн применим к Lorenzo-оркестратору: минимальный агент без MCP-оверхеда,  
только llama-cpp + список команд → `improve_*.py`.

## Возможные комбинации

| Комбинация | Новое свойство |
|------------|----------------|
