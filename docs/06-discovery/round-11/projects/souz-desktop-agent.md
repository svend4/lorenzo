**Уникальность:** Десктопный AI-агент с **70+ инструментами**: email, calendar, files, browser, Telegram. Изначально создан для незрячих людей (распознавание экрана + управление мышью/клавиатурой). Kotlin + MCP + поддержка Anthropic и других LLM. macOS. Открыт как Open Source.

## Что умеет (70+ инструментов)

| Категория | Примеры |
|-----------|---------|
| Файлы | открыть, переместить, найти |
| Браузер | открыть страницу, нажать элемент |
| Почта + календарь | отправить письмо, создать встречу |
| Telegram | отправить сообщение |
| Системные | кликнуть мышью, нажать hotkey, написать текст |
| Скрин | распознать экран → описать → действовать |

## История: built for accessibility

Проект изначально создавался для людей с нарушением зрения:  
агент распознаёт экран, понимает интерфейс, совершает действия голосом/командой.  
После — открыт как OSS с фокусом на безопасность каждого инструмента.

## Стек

- **Kotlin** (Kotlin Multiplatform — планируется расширение)
- **MCP** — протокол для инструментов
- **LLM** — Anthropic + другие провайдеры
- **macOS** — основная платформа

## Почему важно для Svyazi

Lorenzo пишет `improve_*.py` скрипты, которые меняют файлы через CLI.  
Союз — готовый каркас десктопного агента с 70+ инструментами на MCP.  
Применимо: Союз как shell для Lorenzo → агент не просто пишет файлы, но управляет всей ОС.

## Возможные комбинации

| Комбинация | Новое свойство |
|------------|----------------|
| **Союз + Lorenzo runner** | Голосовая команда → run_improve → файл изменён |
| **Союз + SocratiCode (R08)** | Понимание кодовой базы + управление macOS/IDE |
| **Союз + openLight (R07)** | Skill catalog → Союз tools как skills |
| **Союз + DevClaw (R06)** | GitHub Issue → Союз открывает IDE → агент пишет код |
