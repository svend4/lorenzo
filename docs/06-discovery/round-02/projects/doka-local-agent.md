**Уникальность:** Десктопное приложение-агент с GUI для России — без VPN, без подписки, без облака. По умолчанию Qwen3. Умеет искать в интернете, открывать страницы, читать контент и отвечать. Показывает каждый шаг: «ищу → открываю → читаю → отвечаю».

## Что делает

- Desktop app с человекопонятным интерфейсом
- Локальная модель (Qwen3 по умолчанию)
- Web-поиск без облака: поиск → парсинг страниц → ответ
- Transparent reasoning: показывает шаги агента пользователю
- Целевая аудитория: российские пользователи без доступа к OpenAI/Anthropic

## Почему интересно для Svyazi

GUI-слой для Svyazi — один из пробелов. Doka показывает как сделать десктопный front-end для локального агента с прозрачными шагами рассуждения.

## Возможные комбинации с Round 01

| Комбинация | Новое свойство |
|------------|----------------|
| **Doka UI + knowledge-space backend** | Desktop-приложение поверх базы знаний Svyazi |
| **Doka + agent-memory-mcp** | Персонализированный агент: помнит предыдущие поиски |
