# Dedoc

**Автор:** ИСП РАН (Институт системного программирования РАН) / @ispras  
**Хабр:** https://habr.com/ru/companies/isp_ras/articles/779390/  
**GitHub:** https://github.com/ispras/dedoc  
**Слой:** ingestion / document-parsing  
**Уникальность:** Единственный российский open-source парсер документов уровня production, который автоматически извлекает **логическую структуру** (заголовки, таблицы, списки, иерархию), а не просто текст. Поддерживает DOC/DOCX, PDF (сканы тоже), HTML, XLS, JSON, RTF.

## Что делает

- Извлекает контент + логическую структуру + таблицы + метаинформацию
- Работает как Python-библиотека или REST-сервис (Docker)
- Поддерживает сканированные PDF через OCR
- Автоматически конвертирует форматы (DJVU→PDF, RTF→DOCX)
- Выдаёт единый JSON со структурой документа

## Почему интересно для Svyazi

Svyazi получает документы через LiteParse — упрощённый парсер. Dedoc — это production-grade замена с полной логической структурой. Особенно ценно для ingestion научных статей, технической документации, отчётов.

## Возможные комбинации с Round 01

| Комбинация | Новое свойство |
|------------|----------------|
| **Dedoc + knowledge-space** | Auto-ingestion pipeline: любой документ → структурированные карточки → граф знаний |
| **Dedoc + LiteParse (nlaik)** | Dedoc как первый слой (структура), LiteParse как второй (evidence extraction) — двухступенчатый ingestion |
| **Dedoc + AgentFS** | Структурированные документы сохраняются в файловой системе с семантикой |
| **Dedoc + mclaude** | Агент читает сложные PDF/DOCX через Dedoc, а не через raw text |
