## Архитектура (роли и модели)

| Роль | Модель | Почему |
|------|--------|--------|
| Оркестратор | Qwen3.5-397B | GPQA 88.4% — лучший reasoning среди open-source |
| Кодер | Kimi K2.5 | Лучший HumanEval, но 125 ГБ весит |
| Tool use | GLM-4.7 | Единственная с реально хорошим function calling |
| Reviewer / Sec | Qwen3.5-397B | IFEval 92.6% — следует инструкциям |

9 логических агентов = полный цикл: request → code → tests → security review → PR

## Ключевой инсайт

> 9 logical agents = 3-4 physical models.  
> У каждой модели — своё сильное место. Нет одной, которая покрывает всё.

Kimi K2.5: лучший HumanEval, но посредственно правит реальные баги.  
Qwen3.5-397B: лучший reasoning, но не лучший кодер.  
GLM-4.7: лучший tool use, но не про code generation.

## Почему важно для Svyazi

Lorenzo уже использует multi-agent принцип через `improve_*.py`.  
Этот паттерн даёт конкретный ответ: как выбрать модель для каждой роли в пайплайне.  
Оркестратор Svyazi = Qwen3.5-397B (reasoning), исполнители = специализированные модели.
