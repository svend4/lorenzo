Специально ориентирован на российских пользователей. Стартует без настройки, модель скачивается автоматически.

## Что умеет

- Веб-поиск → открытие страниц → чтение → структурированный ответ
- Долговременная память (между сессиями)
- Автовыбор модели под доступное железо
- Фоновые задачи (monitoring loop)
- Без демона, без GUI — запустил и работает

## Сценарии использования автора

| Задача | Описание |
|--------|---------|
| Пре-рисёрч | «Разберись, как работает X, объясни плюсы и минусы» — 5 мин вместо часа |
| Мониторинг индустрии | «Что вышло в ML и backend вчера» — утренний дайджест |
| Подготовка к проектам | Поиск + синтез информации по незнакомой теме |

## Чем отличается от Ботинок (R06)

| Аспект | Ботинок (R06) | Этот агент |
|--------|---------------|------------|
| Среда | SSH / серверная | Десктоп / личная |
| Веб-доступ | Нет | Да (поиск + чтение) |
| Память | Нет | Долговременная |
| Задача | CLI-автоматизация | Исследование и мониторинг |

## Почему важно для Svyazi

Lorenzo нужен аналог для сбора данных о проектах (ingestion layer).  
Паттерн «web search → read → memory → digest» — это и есть Svyazi discovery loop.  
Архитектура этого агента может стать основой `improve_digest_auto.py` с веб-источниками.

## Возможные комбинации

| Комбинация | Новое свойство |
|------------|----------------|
| **Локальный агент + Lorenzo ingestion** | Автоматический сбор новостей с Хабра в карточки |
| **Локальный агент + News System (R05)** | Локальный агент как lightweight альтернатива 5-агентному пайплайну |
| **Локальный агент + Natasha (R05)** | Веб-поиск → NER на русском → структурированные карточки |
| **Локальный агент + Memory MCP v2 (R06)** | Память исследований в engineering memory backbone |
