## Что построили

- Веб-приложение с флешкартами (spaced repetition)
- AI-тренер: задаёт вопросы, оценивает ответы, адаптирует сложность
- Полный стек: backend + frontend + БД
- Разработано человеком (архитектура, review) + AI-агентами (реализация)

## Паттерн коллаборации

```
Человек: ставит задачу, задаёт архитектуру
AI-агент: пишет код, тесты, конфигурацию
Человек: review, правки, мердж
Результат: работающий SaaS за обозримое время
```

Отличается от DevClaw (R06) — там GitHub Issues как интерфейс, здесь прямая сессия с агентом.

## Почему важно для Svyazi

Lorenzo — это Knowledge OS. Следующий логичный слой — **обучение знаниям из базы**.  
Паттерн «флешкарты из документов» применим к Lorenzo-карточкам:  
`improve_*.py` создаёт базу → AI-тренер генерирует вопросы → spaced repetition по corpus Лоренцо.

## Возможные комбинации

| Комбинация | Новое свойство |
|------------|----------------|
| **Flashcard паттерн + Lorenzo corpus** | Карточки Lorenzo → учебные флешкарты по базе знаний |
| **Flashcard паттерн + Natasha (R05)** | NLP-извлечение фактов → автогенерация вопросов |
| **Flashcard паттерн + improve_qa.py** | Q&A листы + AI-тренер → интерактивное обучение |
| **Flashcard паттерн + DevClaw (R06)** | GitHub Issues → агент строит учебный модуль |
