## Как работает

```
Seed-документ (описание мира)
        ↓
  Граф сущностей + отношений
        ↓
  Генерация агентов (уникальная личность + память)
        ↓
  Симуляция в Twitter/Reddit-подобной среде
        ↓
  Отчёт: как мир реагирует на событие
```

## Почему важно для Svyazi

Lorenzo собирает корпус из 2483 карточек — это **seed-база для MiroFish**.  
Паттерн «документы → агенты → симуляция» = способ валидировать гипотезы Svyazi:  
как сообщество OSS-разработчиков отреагирует на открытый Lorenzo?

## Возможные комбинации

| Комбинация | Новое свойство |
|------------|----------------|
| **MiroFish + Lorenzo corpus** | 2483 карточки → агенты OSS-разработчиков → симуляция реакции сообщества |
| **MiroFish-Offline + GraphRAG (R09)** | Neo4j граф + Ollama → локальная симуляция без облака |
| **MiroFish + Natasha (R05)** | NER → граф сущностей для seed-документа на русском |
| **MiroFish + HMP (R09)** | HMP как протокол для агентов MiroFish-mesh |
