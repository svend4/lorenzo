**Уникальность:** Инструмент генерации Rust-кода из текстового объяснения: LLM пишет код → компилирует → разрешает зависимости Cargo → генерирует тесты. Closed loop: агент итерирует до успешной компиляции. Попытка применить LLM к языку с жёстким компилятором.

## Как работает

```
Текстовое объяснение задачи
        ↓
  LLM генерирует Rust-код
        ↓
  rustc компиляция (строгая проверка типов + borrow checker)
        ↓
  При ошибке: LLM читает ошибку → исправляет → снова компиляция
        ↓
  Cargo зависимости + тесты
```

## Уникальная сложность

Rust — один из самых сложных языков для LLM из-за:
- **Borrow checker**: ownership, lifetime, borrowing — LLM часто ошибается
- **Строгая типизация**: нет implicit conversion
- **Cargo экосистема**: правильный выбор crates

Rustsn — эксперимент: насколько хорошо LLM справляется с этими ограничениями в замкнутом цикле.

## Почему важно для Svyazi

Lorenzo пишет скрипты на Python. Если критические части (поиск BM25, индексы) переписать на Rust:  
- BM25 на Rust vs Python → 10–100× ускорение
- `utils_chunker.py` → Rust библиотека с Python bindings (PyO3)

Rustsn = инструмент для такой миграции без ручного написания Rust.

## Возможные комбинации

| Комбинация | Новое свойство |

| **Rustsn + improve_passage_retrieval** | BM25 переписан на Rust → Python bindings → 10× быстрее |
