**Уникальность:** Автор нашёл, что Playwright MCP сжигает в **50 раз больше токенов**, чем CLI на той же задаче (114k токенов на тест). За 3 дня написал собственный инструмент без MCP-оверхеда: axe-core + console + network audit + bug fingerprinting + интеграция с Linear/GitHub/Jira.

## Что делает

- AI-powered веб-тестирование через Claude Code + Playwright (без MCP-слоя)
- axe-core — автоматический аудит accessibility
- bug fingerprinting — классификация багов между прогонами
- Интеграция трекеров: Linear / GitHub Issues / Jira
- Автоматический severity на основе axe impact

## Ключевое архитектурное открытие

> Playwright MCP ≈ 114k токенов/тест  
> CLI напрямую ≈ 2k токенов/тест  
> Разница: **57×**

Это меняет взгляд на MCP: для высокочастотных задач MCP-слой — антипаттерн.

## Почему интересно для Svyazi

Lorenzo запускает `improve_*.py` скрипты через MCP-инструмент `run_improve`. Если по аналогии некоторые вызовы дешевле делать напрямую через CLI — это архитектурный insight для оптимизации токен-затрат.
