## Что делает

Генерация музыки с текстом (lyrics) по описанию или теме:
- **HeartLib** — основная библиотека генерации (3B параметров)
- **HeartCodec** — специализированный аудиокодек 12.5 Hz для музыки
- **HeartTranscriptor** — транскрипция и выравнивание слов (Whisper-based)
- **HeartCLAP** — CLAP-совместимый аудио-текстовый embedding

## Почему важно для Svyazi

Свободная лицензия (Apache 2.0) = можно встраивать в Svyazi без ограничений.  
HeartCLAP — аудио-текстовые embeddings → возможен поиск по звуку в будущем.  
Паттерн «кодек + генератор + транскриптор» воспроизводим для других модальностей.  
Lorenzo использует голосовой pipeline (RPi Agent R11, Ирина R02) — HeartMuLa добавляет генерацию, а не только STT/TTS.

## Возможные комбинации

| Комбинация | Новое свойство |
|------------|----------------|
| **HeartMuLa + Ирина (R02)** | Ирина (TTS русской речи) + HeartMuLa (генерация музыки) = полный аудио-пайплайн |
| **HeartMuLa + RPi Agent (R11)** | Офлайн-генерация фоновой музыки на edge-железе |
| **HeartMuLa + Knowledge OS** | Sonification: озвучивание дайджестов / уведомлений агентов |
| **HeartCLAP + search_index** | Мультимодальный поиск: аудио → текст → карточки базы знаний |

## Контакт

- GitHub: https://github.com/HeartMuLa/heartlib
- PyPI: pip install heartlib
- ⚠️ Для локального запуска нужно ~24 ГБ VRAM; через API — без ограничений по железу
