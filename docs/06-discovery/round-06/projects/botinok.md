**Уникальность:** Консольный AI-агент, спроектированный специально для SSH-окружений и машин с малым VRAM. Работает без демонов, без сервисов, без GUI — только терминал. Минимум: qwen3.5:4b на 8 ГБ VRAM. Цель — полноценный агент в среде, где нельзя запустить тяжёлый стек.

## Что делает

- Консольный агент на основе локальной LLM (Qwen3.5, ollama)
- Запускается по SSH без постоянного демона
- Нет зависимостей на облако, нет GUI
- Команды напрямую в терминале
- Минимальный footprint: 8 ГБ VRAM (qwen3.5:4b)

## Ключевое архитектурное решение

Антипаттерн «MCP-агент с GUI» для серверных окружений: всё лишнее убрано.  
Только STDIN/STDOUT + локальная LLM. Близко к принципу AI Web Tester (R05): убрать слои — получить 50× экономию ресурсов.

## Почему интересно для Svyazi

Lorenzo запускается локально, скрипты `improve_*.py` вызываются из CLI.  
Паттерн «минимальный агент для CLI» — прямое вдохновение для легковесного Svyazi-оркестратора без MCP-оверхеда на CI-серверах или VPS.

## Возможные комбинации

| Комбинация | Новое свойство |
|------------|----------------|
| **Ботинок + Lorenzo runner** | Запуск improve_*.py через SSH без GUI |
| **Ботинок + AI Web Tester (R05)** | CLI-first подход: нет MCP = экономия токенов |
| **Ботинок + TRAIL spec (R04)** | Минимальный агент как исполнитель TRAIL-пайплайна |
| **Ботинок + Coreness Flow (R02)** | YAML-воркфлоу без GUI в SSH-окружении |
