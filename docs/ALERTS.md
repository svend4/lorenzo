# Callout-блоки

Добавлено **61** callout-блоков в документы.

| Тип | Количество | Назначение |
|-----|------------|------------|
| `[!NOTE]` | 25 | Нейтральная заметка |
| `[!TIP]` | 28 | Практический совет |
| `[!WARNING]` | 7 | Предупреждение о риске |

## Пример синтаксиса

```markdown
> [!NOTE]
> Это заметка.

> [!TIP]
> Практический совет.

> [!WARNING]
> Предупреждение.

> [!IMPORTANT]
> Важная информация.
```
