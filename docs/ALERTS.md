Добавлено **680** callout-блоков в документы.

| Тип | Количество | Назначение |
|-----|------------|------------|
| `[!NOTE]` | 680 | Нейтральная заметка |
| `[!TIP]` | 0 | Практический совет |
| `[!WARNING]` | 0 | Предупреждение о риске |
| `[!IMPORTANT]` | 0 | Ключевой документ |

## Пример синтаксиса

```markdown
> [!NOTE]
> Это заметка.

> [!TIP]
> Практический совет.

> [!WARNING]
> Предупреждение.

> [!IMPORTANT]
> Важная информация.
```

_Поддерживается в GitHub Markdown с 2023 года._
