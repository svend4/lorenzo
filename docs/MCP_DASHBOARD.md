# MCP Dashboard

<!-- toc-auto -->
## Содержание



<!-- summary -->
> Статистика вызовов MCP-серверов репозитория Lorenzo: инструменты, частота, ошибки.

<!-- tags: mcp, dashboard, monitoring, tools -->

> [!NOTE]
> MCP Dashboard обновляется скриптом `improve_mcp_dashboard.py`. Для сбора статистики нужны логи вызовов.

<!-- alert-added -->

_Логи MCP-вызовов отсутствуют._

MCP Dashboard отображает статистику использования MCP-серверов: какие инструменты вызывались, с какой частотой, какой процент вызовов завершился ошибкой. Данные накапливаются в лог-файлах при работе с MCP-сервером репозитория. Для запуска MCP-сервера используйте `scripts/mcp_server.py`.

## Использование

```bash
python scripts/improve_mcp_dashboard.py
```

```bash
# Запустить MCP-сервер
python scripts/mcp_server.py
```

Документ индексирован в базе знаний репозитория. Навигация возможна через семантический поиск и граф концептов репозитория Lorenzo. Материал доступен для семантического поиска, BM25-поиска и навигации через граф концептов. Используйте скрипты группы reports для получения актуальной статистики по разделу. Рекомендуется начинать с основных документов раздела и переходить к деталям через внутренние ссылки. Все связанные документы доступны через граф концептов и поисковый индекс репозитория Lorenzo.
