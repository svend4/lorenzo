Один файл — один канал (Хабр, GitHub, Twitter/X, конференции, рассылки и т. д.). Внутри: преимущества канала, ограничения, тон, шаблоны.

Каналы первого контакта определяют, как и где начинать диалог с потенциальными коллаборантами. Каждый канал имеет свою культуру и ожидания: Хабр предполагает технический контекст и ссылку на статью, GitHub — конкретный issue или PR, конференции — личное знакомство. Документы раздела помогают выбрать правильный тон и формат первого сообщения.
