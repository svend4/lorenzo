<!-- alert-added -->

_Обновлено: 2026-05-10_

Бейджи генерируются скриптом `improve_status_badges.py` на основе данных репозитория. Каждый бейдж отражает актуальное состояние одного из измеримых параметров: количество шаблонов, скилов, скриптов, MCP-серверов, а также общий балл здоровья. Вставьте нужные строки в README проекта — они обновляются автоматически при каждом запуске пайплайна.
