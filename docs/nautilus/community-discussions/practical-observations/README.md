Документы раздела индексированы в поисковой базе репозитория Lorenzo и доступны для семантического поиска, BM25-поиска и навигации через граф концептов. Каждый файл содержит структурированный анализ согласно стандартам документации. Используйте инструменты improve_run_all.py для автоматического обновления раздела.

Навигация по разделу возможна через семантический поиск и граф связей репозитория. Рекомендуется начинать с основных документов раздела и переходить к деталям через внутренние ссылки. Для получения актуальной статистики запустите.
