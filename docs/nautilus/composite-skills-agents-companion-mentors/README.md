Документы структурированы по стандарту базы знаний: summary-блок, теги, callout, оглавление и ссылки. Раздел обновляется автоматически при запуске скриптов группы reports и quality из пакета improve_*.py. Для автоматизации работы с разделом используйте скрипты группы improve_run_all.py с флагом --group.
