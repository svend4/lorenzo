```bash
python scripts/improve_semantic_search.py --query "privacy federation"
```

Используйте инструменты репозитория для навигации: семантический поиск, BM25, граф концептов и карту связей. Документы структурированы по стандарту базы знаний: summary-блок, теги, callout, оглавление и ссылки. Раздел обновляется автоматически при запуске скриптов группы reports и quality из пакета improve_*.py.
