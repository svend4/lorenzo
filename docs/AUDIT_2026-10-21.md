### 4.1. Безопасность сервисов

**H-SEC-1. Gateway `POST /api/cards`: обход пути через `section` → запись `.md` вне `docs/`** (security-gateway-mcp-1, mcp-gateway-runtime-4). `scripts/gateway.py:534` `target_dir = DOCS / section`, `:566` `filepath.write_text(md)` без валидации. Воспроизведено через `fastapi.testclient`: `section="../../tmp/lorenzo_traversal_probe"` → 200 «✅ Карточка создана: docs/../../tmp/…», файл создан за пределами `docs/`. Сервер по умолчанию `--host 0.0.0.0` (`:1082`), `allow_origins=["*"]` (`:82`), аутентификации и rate-limit нет (100×GET за 0.38 с, 30×POST `/api/search` ≈ 23 с CPU). *Фикс:* allow-list секций + `(DOCS/section).resolve().is_relative_to(DOCS.resolve())`; `--host 127.0.0.1` по умолчанию; bearer-token на write; token-bucket.

**H-SEC-2. MCP write-инструменты: обход пути в `add_card`, `update_card_state`, `decay_card`, `restore_card`** (security-gateway-mcp-2). `scripts/mcp_server.py:1099` `target = DOCS / section`; `:1166` `filepath = ROOT / path_str` — абсолютный путь заменяет `ROOT`, `../` выходит вверх; `:1175-1188` читает и **переписывает** файл, добавляя frontmatter — т.е. любой файл под `ROOT` (включая `scripts/*.py`, `.github/workflows/*.yml`) можно испортить через prompt-injection из корпуса. *Фикс:* резолв и проверка границы `DOCS` перед любым чтением/записью; запрет абсолютных путей и `..`.

**H-SEC-3. docs-toolkit: инъекция аргументов git через `ref`/`commit`** (security-toolkit-1). `docstoolkit/diff/bulk.py:200` `['git','diff','--name-status', commit_a, commit_b]` без `--`; то же в `temporal/queries.py:90`, `temporal/snapshot.py:112`, `timetravel/git.py:16`. `commit_a='--output=/path'` заставляет git записать файл. **H-SEC-4. `plugin_sandbox` — не песочница** (security-toolkit-2, toolkit-B-7). `docstoolkit/plugin_sandbox/sandbox.py:155` — `exec()` в потоке процесса; `SandboxPolicy()` по умолчанию отдаёт полный `builtins`; при `allow_builtins=[]`/`allow_imports=[]` обход в одну строку через `().__class__.__base__.__subclasses__()` → `BuiltinImporter.load_module('posix')` (воспроизведено: `execute()` вернул `success=True`). Таймаут не убивает C-код. `SECURITY.md` и `PLUGIN_CONTRACT.md` документируют несуществующий API (`run_in_sandbox`, `allow_subprocess`, `max_memory_mb`). *Фикс:* не позиционировать как границу безопасности; убрать документацию несуществующих гарантий; при необходимости — отдельный процесс/контейнер.

**H-SEC-5 (понижено до среднего скептиком). `.claude/settings.json` разрешает без подтверждения `Bash(python -c *)`, `git commit*`, `git push*`, любые `python scripts/improve_*.py*`** (secrets-pii-3). Файл отслеживается, deny-списка нет. Для автономных запусков (`improve_watcher.py`, субагенты) это произвольное выполнение кода + публикация в публичный репо. *Фикс:* убрать `python -c *`, `git push*`; сузить improve до `--dry-run/--stats/--list`; deny на `--apply`, `improve_llm_*`; заменить префиксы `grep*`/`ls*` на `grep *`/`ls *`.
